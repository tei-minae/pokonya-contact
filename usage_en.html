Instruction Manual

Thank you for purchasing "Whip Cream Pasties". This product is designed for easy installation using Modular Avatar.

📋 Prerequisites

Please ensure the following tools are imported into your Unity project before importing this package:
  • lilToon (Shader)
  • Modular Avatar (Outfit Management Tool)

🚀 Installation Steps

  1. Import the UnityPackage.
  2. Choose one of the 6 color variations from the Prefabs folder.
  3. Drag and drop the selected prefab directly under your Avatar Object in the scene.
⚠️ NOTE: The mesh is hidden by default!
The mesh is set to be invisible initially. It will appear when you toggle the switch ON via the Expression Menu in VRChat.

🛠 Customization

Adjust the fit according to your avatar's chest size.

Shapekey Adjustments:
The mesh includes multiple shapekeys for adjusting position and size. Please fine-tune them to perfectly match your avatar's body type.

💡 Usage on Other Avatars

This product is optimized for the "Shinano" avatar and has high compatibility with "Mochi Fitter". When using this product with other avatars, we strongly recommend using Mochi Fitter for the best fit.
